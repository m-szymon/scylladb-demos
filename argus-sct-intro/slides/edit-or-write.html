What do I touch? Start at the top

Change a value, same test

Env var in Argus, or edit the YAML

Duration, config path, versions, node counts. No code, no new job.

New variant of an existing test

New test-case YAML

A new YAML under test-cases and a jenkinsfile pointing at it. Or clone the job in Argus and override values.

New behaviour or new result

New or changed test class

Python, unit tests, a jenkinsfile, an Argus page. Follow docs/writing-a-test.md.

Checklist for a new test: test class, YAML with test_metadata, jenkinsfile, Argus page, unit tests, docs.

Most requests from the team will be the first row. Make that explicit so people do not open the Python when they only need a value changed. The third row is the only one that needs a review from the SCT maintainers.
